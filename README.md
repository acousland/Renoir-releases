# Renoir for macOS releases

Release builds of Renoir, a local diagram renderer for architecture drawings, and the feed the app uses to update itself.

Download the latest DMG from [Releases](https://github.com/acousland/Renoir-releases/releases/latest), open it, and drag **Renoir.app** to **Applications**. Renoir then checks for new versions itself and installs them after checking each one against its signing key.

Requires macOS 14 or newer on Apple silicon. The latest installer is Developer ID signed and notarised by Apple.
